# FitLife - Mobile-First Responsive Design (exp3)

## Aim
Create a simple, mobile-first responsive landing page for a fitness company using Tailwind CSS.

## Features

### 1. Header & Navigation
- Brand name: FitLife
- Mobile: Hamburger menu (vertical)
- Desktop: Horizontal navigation menu

### 2. Hero Section
- Gradient background
- Heading, description, and "Join Now" button

### 3. Services Section (3 Cards)
**Responsive Grid:**
- Mobile: 1 column
- Tablet (md): 2 columns
- Desktop (lg): 3 columns

**Programs:**
- 🏋️ Weight Training
- 🧘 Yoga Classes
- 🥗 Diet Plans

### 4. Trainers Section
- 3 trainer cards with emoji avatars
- Names and specializations

### 5. Footer
- Contact info (email, phone)
- Copyright text

## Tailwind CSS Features Used
- Responsive breakpoints: `md:`, `lg:`
- Grid layout: `grid-cols-1 md:grid-cols-2 lg:grid-cols-3`
- Spacing: `py-12`, `px-4`, `gap-6`
- Typography: `text-3xl`, `font-bold`
- Colors: `bg-purple-600`, `text-white`
- Hover effects: `hover:shadow-xl`, `hover:bg-purple-700`

## Getting Started
Simply open `index.html` in a browser. No build process needed!
