Introduction to variables, data types, and basic operations in JavaScript.

Rules for Variables in JavaScript

  • letters digits underscore and dollar sign are allowed in variable names

  • javascript reserved words can not be used as variable names e.g. const, undef,

  • Case Sensitive - variable names are case sensitive e.g. abes and ABES are different

  • var is globally scoped with Y while let and const are block scoped

  • var can be updated and re-declared withinin it's scope

  • let can be updated but not re-declared within its scope

  • const can not be updated or re-declared within its scope

  • var variables are initialized with undefined value whereas let and const variables are not initialized with any value

  • const must be initialized during declaration unlike let and var
